<h3>Quotes Listing Application</h3>
<p>A simple Quotes Generator web application built using JavaScript and the FreeAPI Quotes API.</p>
<p>Users can search quotes by author name and view matching quotes dynamically on the screen.</p>

<h3>API link</h3>
<p>https://api.freeapi.app/api/v1/public/quotes</p>
